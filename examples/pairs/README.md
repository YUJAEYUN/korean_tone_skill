# Before/After 대조 예문 뱅크

이 디렉토리가 **이 스킬의 가장 중요한 자산**입니다. 규칙을 나열하는 것보다 실제
대조 예문이 목표 문체를 훨씬 정확하게 전달합니다.

## 목표

- 최종 목표: 100~200쌍
- 현재: 아래 3개 파일에 장르별로 초기 시드 예문이 들어 있습니다 (총 15쌍).
  **이건 시작점이지 완성본이 아닙니다.** 실제 윤문 작업을 하면서 계속 쌓아가세요.

## 파일 구성

| 파일 | 장르 |
|---|---|
| `informational.md` | 정보 전달(설명글) |
| `essay.md` | 의견/에세이 |
| `practical.md` | 실용문(안내/공지/이메일) |

## 예문 추가 방법

가장 좋은 방법은 **실제 작업에서 나온 쌍을 저장하는 것**입니다.

1. Claude에게 아무 주제로나 글을 쓰게 한다 (또는 실제 AI 생성 텍스트를 가져온다).
2. 사용자가 직접 자연스럽게 고친다.
3. 아래 형식으로 해당 장르 파일에 추가한다.

```markdown
### N. 짧은 제목

**Before (AI체/원문)**
> (원문 그대로)

**After (쉬운 표준 한국어)**
> (고친 글)

**바뀐 것**: (한 줄로 — 어떤 패턴을 어떻게 고쳤는지. plain-vocabulary-map.md나
ai-tell-catalog.md의 패턴명을 인용하면 좋음)
```

## 주의

- `examples/style-samples/`에는 저작권 있는 원문을 그대로 담지 않습니다. 패턴만
  추출해 직접 쓴 예문으로 대체하세요 (해당 디렉토리의 README 참고).
- 예문은 특정 정치·종교적 입장을 담지 않는 중립적 소재(과학, 생활, 기술, 사회 일반)로
  구성하는 것을 권장합니다.
