# 목표 문체 원문 발췌 — 저작권 주의

설계서(0번 원칙 4 "의미 보존")와 별개로, 이 디렉토리는 **저작권 있는 원문을 그대로
담지 않습니다.**

## 방침

- 실제 좋은 예시 글(신문 칼럼, 에세이 등)에서 배울 점이 있다면, 원문을 복사하지 말고
  **패턴만 추출**하세요: 문장 길이 분포, 예시 배치 시점, 접속어 사용 빈도 등.
- 추출한 패턴은 직접 새로 쓴 예문으로 재현해 `examples/pairs/`에 넣거나, 이 파일에
  "관찰된 패턴" 형태로 짧게 메모합니다.
- 저작권자의 허락 없이 긴 원문 발췌를 커밋하지 않습니다.

## 관찰된 패턴 메모 (예시 형식)

```markdown
### 출처: (매체/장르, 구체적 URL·서지정보는 생략 가능)
- 관찰: 문장 평균 길이가 짧고(15자 내외), 3문장에 한 번꼴로 대화체 어미 사용
- 관찰: 전문용어 등장 시 바로 다음 문장에서 쉬운 말로 재진술
- 적용: `examples/pairs/`의 어느 예문에 이 패턴을 반영했는지 링크
```

현재는 비어 있습니다. 실제 작업 중 발견한 패턴을 이 형식으로 채워나가세요.
