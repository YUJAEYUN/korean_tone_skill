# 최종 검증 게이트

## 1. 불변 조건 — 하나라도 실패하면 전체 실패

- 숫자, 날짜, 단위, 인명, 기관명, 제품명이 보존됐는가?
- 인과관계와 시간 순서가 뒤바뀌지 않았는가?
- 긍정·부정, 가능·불가능, 의무·권고가 바뀌지 않았는가?
- 직접 인용과 출처를 임의로 고치지 않았는가?
- 핵심 주장, 조건, 예외, 불확실성이 보존됐는가?
- 사실이나 근거를 새로 만들어 넣지 않았는가?

## 2. 목적 적합성 — 상황 프로필에 맞춰 검사

- 독자가 핵심 내용을 빠르게 찾을 수 있는가?
- 독자가 읽은 뒤 해야 할 행동이 분명한가?
- 독자의 전문성과 배경지식에 맞는가?
- 매체의 길이와 읽기 환경에 맞는가?
- 위험도에 맞게 경고, 조건, 예외가 드러나는가?

## 3. 표현 품질

- 주어와 서술어, 조사와 접속 표현이 자연스러운가?
- 관계와 상황에 맞는 격식이 일관되는가?
- 쉬운 말로 바꾸다가 정확성이 떨어지지 않았는가?
- 같은 말의 반복, 불필요한 수식, 상투적인 AI 표현이 남지 않았는가?
- 원래부터 좋은 문장을 불필요하게 바꾸지 않았는가?

## 판정

- **통과**: 불변 조건을 모두 지키고 목적 달성을 방해하는 문제가 없음
- **수정 후 통과**: 사용자가 수정을 허용한 경우에만 문제를 바로잡고 다시 검사함
- **확인 필요**: 사용자 결정 또는 외부 사실 확인 없이는 안전하게 확정할 수 없음
