# 한국어 글쓰기 최종 검증

`references/validation-gates.md`의 순서대로 검사한다.

1. **불변 조건 게이트**를 먼저 검사한다. 하나라도 실패하면 표현 품질과 관계없이 실패로 판정한다.
2. **목적 적합성 게이트**로 독자가 필요한 정보를 찾고 다음 행동을 할 수 있는지 확인한다.
3. **표현 품질 게이트**로 문법, 연결, 톤, 불필요한 난도를 확인한다.
4. 원문이 없는 새 글은 사용자 요구사항과 상황 프로필을 원문 대신 기준으로 삼는다.
5. 확인할 수 없는 사실을 지어내지 않는다. 확인이 필요한 내용은 표시한다.

## 실행 모드

- **독립 모드**: 검증만 요청받으면 원문을 고치지 않고 통과·실패·확인 필요와 근거를 보고한다.
- **위임 모드**: 오케스트레이터가 호출하면 실패 원인을 반환하고, 오케스트레이터가 수정한 결과를 다시 검증한다. 검증기가 몰래 수정해 통과 처리하지 않는다.
- **검증 및 수정 모드**: 사용자가 검증과 수정을 함께 요청했을 때만 문제를 고친 뒤 `수정 후 통과`로 보고한다.

검증을 통과했다는 문구는 실제로 원문 또는 작성 요구사항과 대조한 뒤에만 쓴다. 비교 기준이 없으면 의미 보존을 추정하지 말고 `확인 필요`로 판정한다.
