# 한국어 글쓰기 최종 검증

`references/validation-gates.md`의 순서대로 검사한다.

1. **불변 조건 게이트**를 먼저 검사한다. 하나라도 실패하면 표현 품질과 관계없이 결과를 수정한다.
2. **목적 적합성 게이트**로 독자가 필요한 정보를 찾고 다음 행동을 할 수 있는지 확인한다.
3. **표현 품질 게이트**로 문법, 연결, 톤, 불필요한 난도를 확인한다.
4. 원문이 없는 새 글은 사용자 요구사항과 상황 프로필을 원문 대신 기준으로 삼는다.
5. 확인할 수 없는 사실을 지어내지 않는다. 확인이 필요한 내용은 표시한다.

검증을 통과했다는 문구는 실제로 대조한 뒤에만 쓴다. 사용자가 결과만 원하면 실패를 바로잡은 최종 글만 출력한다.
