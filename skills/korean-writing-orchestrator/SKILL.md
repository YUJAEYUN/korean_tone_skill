# 한국어 글쓰기 오케스트레이터

하나의 문체를 강요하지 말고, 독자가 해당 상황에서 목적을 달성하기 쉬운 글을 만든다.

## 작업 순서

1. 사용자가 진단만 원하는지, 부분 수정인지, 전체 재작성인지, 새 글 작성인지 확인한다.
2. `../korean-writing-context/SKILL.md`를 적용해 상황 프로필을 만든다. 정보가 없으면 원문에서 추론하고, 결과에 큰 영향을 주는 정보만 사용자에게 묻는다.
3. `references/priority-matrix.md`로 품질 우선순위를 정한다.
4. `references/routing-rules.md`에 따라 필요한 전문 스킬만 선택한다. 모든 스킬을 기계적으로 순회하지 않는다.
5. `references/handoff-contract.md`로 원문, 현재 수정본, 보존 조건과 변경 기록을 모든 단계에 함께 전달한다.
6. 필요한 범위 안에서 **내용과 구조 → 논리 → 문장 → 어휘 → 톤 → AI체** 순서로 처리한다. 전용 스킬이 없는 단계는 일반 원칙으로 점검하되 별도 스킬을 적용했다고 표현하지 않는다. 앞 단계의 결정을 뒤 단계가 뒤집지 않게 한다.
7. 수정 요청에서 원문이 이미 목적에 맞으면 고치지 않는다. 변경량을 성과로 여기지 않는다.
8. 수정 후 `../korean-writing-validator/SKILL.md`를 **위임 모드**로 적용한다. 실패 항목이 있으면 결과를 내기 전에 고친다.
9. `references/output-contract.md` 형식으로 답한다. 사용자가 결과만 원하면 내부 분석은 생략하고 최종 글만 보여 준다.

## 절대 우선순위

규칙이 충돌하면 다음 순서를 적용한다.

1. 사실·의미·안전
2. 글의 목적
3. 독자의 이해와 행동
4. 논리와 구조
5. 관계와 격식
6. 자연스러운 표현
7. AI체 제거

쉬운 말이나 자연스러운 문장을 위해 전문용어, 조건, 불확실성 또는 필자의 핵심 주장을 훼손하지 않는다.

## 현재 연결된 전문 스킬

- **상황 분석**: `../korean-writing-context/SKILL.md`
- **쉬운 한국어 재작성**: `../korean-plain-writer/SKILL.md`
- **최종 검증**: `../korean-writing-validator/SKILL.md`

구조·논리·톤 전용 스킬은 근거와 평가 사례가 충분히 쌓인 뒤 분리한다. 지금은 불필요한 호출 계층을 만들지 않는다.
