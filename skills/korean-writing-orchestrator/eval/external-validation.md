# LLM 채점자 외부 검증 (전문가 채점 데이터 대조)

`judges/composition-quality-rubric.md`로 채점하는 LLM 채점자가 믿을 만한지는 지금까지
확인한 적이 없습니다. 사람 채점자를 늘리기 어려우니, 전문가가 이미 채점해 둔 한국어
글에 우리 채점자를 돌려 점수가 얼마나 맞는지 먼저 봅니다.

## 데이터: AI Hub 「에세이 글 평가 데이터」

- 주소: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=545
- 에세이 50,413편. 전문가 3명이 글마다 최대 11개 항목을 0~3점으로 채점
  (2026-09-27 데이터 소개 페이지에서 확인).
  - 표현: 문법(exp_grammar), 어휘(exp_vocab), 문장 표현(exp_style)
  - 구성: 문단 간 구조(org_essay), 문단 내 구조(org_paragraph), 구조의 일관성
    (org_coherence), 분량(org_quantity), 전체 구성(org)
  - 내용: 주제 명료성(con_clearance), 독창성(con_novelty), 과제 이해(con_prompt),
    서술력(con_description)
- **받는 방법**: AI Hub 로그인 후 데이터 신청과 승인이 필요하고, 페이지에 "내국인만 데이터
  신청이 가능합니다"라고 적혀 있습니다. 계정 소유자가 직접 신청해야 합니다.
- **저장소에 넣지 않습니다.** 받은 원본과 채점 결과는 저장소 밖에 두고, 여기에는 집계
  수치만 남깁니다. 재배포 조건을 확인하기 전까지는 에세이 원문도 커밋하지 않습니다.

## 절차

1. 데이터 설명서에서 항목별 세부 채점 기준(0~3점 각각의 기술)을 확인합니다. 이 문서의
   항목 이름은 소개 페이지 기준이고, 세부 기준은 아직 보지 못했습니다.
2. 장르·학년이 고루 섞이게 에세이 100편 정도를 뽑습니다. 채점자를 고치는 데 쓸 50편
   (dev)과, 고친 뒤 한 번만 확인할 50편(validation)으로 나눕니다.
3. LLM 채점자에게 에세이와 설명서의 채점 기준만 주고 11개 항목을 0~3점으로 매기게 합니다.
   전문가 점수, 다른 채점 결과는 보여 주지 않습니다.
4. 결과를 아래 형식의 JSONL로 만들고 `../../korean-plain-writer/scripts/judge_agreement.py`를
   돌립니다.

   ```json
   {"id": "essay-001", "item": "exp_grammar", "experts": [2, 3, 2], "judge": 2}
   ```

5. 항목마다 LLM↔전문가 값을 **전문가↔전문가 값과 비교**합니다. 전문가끼리도 완전히 일치하지
   않으므로, LLM 채점자가 그 수준에 가까우면 "전문가 한 명을 더 쓴 정도"로 믿을 수 있습니다.

## 지표

국립국어원 2026 AI 언어 평가 「글쓰기 채점 능력 평가」 과제가 쓰는 RMSE와 Spearman
상관계수에, 서열 척도 채점에서 표준인 QWK(quadratic weighted kappa, Cohen 1968)를
더했습니다.

| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| Spearman | 글들의 순위를 같게 매기는가 | 1에 가까울수록 |
| RMSE | 점수가 평균적으로 몇 점 어긋나는가 | 0에 가까울수록 |
| QWK | 우연히 맞을 확률을 빼고, 크게 어긋날수록 더 벌점을 준 일치도 | 1에 가까울수록 |

## 결과를 어떻게 쓸까

- 전문가 수준에 가까운 항목만 LLM 채점을 믿고, 먼 항목은 사람 채점을 유지합니다. 창작·감상
  글은 LLM 채점자가 전문가와 잘 맞지 않는다는 연구가 있습니다(LitBench 2025, TTCW 2024,
  `../../korean-plain-writer/eval/related-work.md` 참고). 내용 항목(독창성 등)에서 낮게 나와도
  이상하지 않습니다.
- 11개 항목 중 우리 5항 채점표(`judges/composition-quality-rubric.md`)와 겹치는 것은 구성
  항목(구조, 일관성)과 서술력입니다. 겹치는 항목의 일치도가 우리 채점표를 믿을 근거가 됩니다.
