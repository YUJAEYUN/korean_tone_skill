# 품질 우선순위표

상황 프로필을 바탕으로 핵심 품질 축을 1~3개 고른다. 억지로 세 개를 채우지 않는다. 의미 보존은 우선순위에 넣어 선택하는 항목이 아니라 모든 상황에서 통과해야 하는 조건이다.

| 상황 | 높은 우선순위 |
|---|---|
| 안전·의료·법률·금융 | 정확성, 조건·예외, 불확실성 |
| 안내·공지·매뉴얼 | 행동 가능성, 명료성, 탐색성 |
| 보고·설명·교육 | 정확성, 이해 가능성, 정보 구조 |
| 제안·설득 | 주장 명료성, 근거, 독자 적합성 |
| 이메일·요청·사과 | 핵심 요청, 관계·예의, 간결성 |
| 에세이·칼럼 | 필자 목소리, 흐름, 자연스러움 |
| UI·알림·모바일 | 즉시 이해, 행동 동사, 짧은 길이 |

낮은 우선순위의 품질을 버리라는 뜻이 아니다. 충돌이 생길 때 무엇을 먼저 지킬지 정하는 표다.
