# 단계 간 전달 계약

각 단계에 최신 수정본만 넘기지 말고 아래 상태를 함께 유지한다.

```yaml
original: 사용자가 준 원문 또는 작성 요구사항
current: 현재 단계의 수정본
context: korean-writing-context가 만든 상황 프로필
preserve: 바꾸면 안 되는 사실, 표현, 조건
scope: 사용자가 허용한 수정 범위
changes: 지금까지 한 주요 변경
open_questions: 확인하지 못한 사실이나 사용자 결정
```

## 규칙

- 모든 단계는 `original`과 `preserve`를 다시 대조한다. 직전 수정본만 기준으로 삼지 않는다.
- 현재 단계의 책임 밖인 내용은 고치지 않는다.
- 앞 단계의 변경을 되돌리거나 보존 조건을 건드리면 변경하지 말고 충돌로 기록한다.
- 사용자가 지정한 `scope`를 전문 스킬의 기본 절차보다 우선한다. 단, 사실·의미·안전을 훼손하라는 범위 제한은 따르지 말고 충돌을 알린다.
- 최종 검증에는 원문, 최종 수정본, 상황 프로필, 보존 조건을 모두 전달한다.
