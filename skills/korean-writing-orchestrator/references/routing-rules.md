# 전문 스킬 선택 규칙

## 항상

1. `korean-writing-context`로 상황을 분석한다.
2. 작성 또는 수정이 끝나면 `korean-writing-validator`로 검증한다.

## 조건부

`korean-plain-writer`는 다음 중 하나일 때 적용한다.

- 사용자가 쉽게, 자연스럽게 또는 AI 티 없이 써 달라고 요청함
- 일반 독자에게 어려운 한자어·번역투·명사화가 많음
- 정보 순서, 장르 톤 또는 표현을 함께 다듬어야 함

다음에는 과도하게 적용하지 않는다.

- 원문이 이미 목적과 독자에게 적합함
- 법률·의료·기술 용어를 쉬운 말로 바꾸면 정확성이 떨어짐
- 사용자가 교정 범위를 맞춤법 등으로 제한함

## 수정 단위

- 구조 문제가 없으면 문단을 재배치하지 않는다.
- 문장 문제가 없으면 어휘만 고친다.
- 문제가 없는 표현은 AI가 쓴 듯하다는 이유만으로 바꾸지 않는다.
