# 의미 보존 채점표

`SKILL.md`의 의미 보존 게이트를 항목별로 **통과/실패**로 채점합니다.
하나라도 실패하면 전체 결과를 실패로 처리합니다. 자연스러움 점수와 합산하지 않습니다.

| 항목 | 통과 기준 |
|---|---|
| 1. 숫자·날짜·고유명사 | 원문에 있던 숫자, 날짜, 인명, 기관명, 제품명이 재작성본에도 모두 있는가 |
| 2. 인과관계 방향 | "X 때문에 Y"가 "Y 때문에 X"로 뒤바뀌지 않았는가 |
| 3. 부정·긍정 | 있다/없다, 가능/불가능, 찬성/반대가 반전되지 않았는가 |
| 4. 직접 인용 | 큰따옴표 안 인용이 원문 그대로인가 |
| 5. 핵심 주장·결론 | 원문의 핵심 메시지가 바뀌지 않았는가 |
| 6. 논리 관계 | 조건·예외·비교·시간 순서가 빠지거나 뒤바뀌지 않았는가 |
| 7. 확신의 강도 | 확정·가능성·추측의 정도가 달라지지 않았는가 |
| 8. 누락·추가 | 중요한 정보를 빼거나 원문에 없는 사실·사례·이유·감정을 넣지 않았는가 |

격식 수준과 글쓴이의 목소리는 중요하지만 의미 보존 점수에 섞지 않고 문체 적합성 축에서
별도로 평가합니다.

## 기록 형식

각 holdout 항목마다 아래 형식으로 채점 결과를 남깁니다.

```markdown
### <항목 이름>

| 항목 | 결과 |
|---|---|
| 1. 숫자·날짜·고유명사 | 통과 |
| 2. 인과관계 방향 | 통과 |
| 3. 부정·긍정 | 통과 |
| 4. 직접 인용 | 해당 없음 |
| 5. 핵심 주장·결론 | 통과 |
| 6. 논리 관계 | 통과 |
| 7. 확신의 강도 | 통과 |
| 8. 누락·추가 | 통과 |

**종합**: 통과
```
