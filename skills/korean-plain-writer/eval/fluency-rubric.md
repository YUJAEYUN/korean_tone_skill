# 유창성 채점표

텍스트 스타일 전이 평가는 보통 스타일·내용·유창성을 서로 다른 축으로 봅니다
(`related-work.md` 1번 참고). 우리는 "자연도 등급"(스타일)과 "의미 보존"(내용)은
이미 따로 채점하고 있었지만, "문법적으로 매끄러운가"(유창성)는 빠져 있었습니다.
패턴을 없애려다 오히려 어색한 문장을 만들 수 있으므로 별도로 확인합니다.

이것도 의미 보존과 마찬가지로 **자연도 등급과 트레이드오프하지 않습니다.** 패턴이
없어졌어도 문법이 어색하면 유창성 실패입니다.

| 항목 | 통과 기준 |
|---|---|
| 1. 주어-서술어 호응 | 문장 끝까지 읽었을 때 주어와 서술어가 자연스럽게 이어지는가 |
| 2. 조사 사용 | 조사(이/가, 을/를, 은/는 등)가 문맥에 맞게 쓰였는가 |
| 3. 접속 표현 | 문장·절을 잇는 연결어미나 접속사가 어색하지 않은가 |
| 4. 끝까지 매끄럽게 읽히는가 | 중간에 걸리거나 다시 읽어야 하는 부분이 없는가 |

## 기록 형식

```markdown
### <항목 이름>

| 항목 | 결과 |
|---|---|
| 1. 주어-서술어 호응 | 통과 |
| 2. 조사 사용 | 통과 |
| 3. 접속 표현 | 통과 |
| 4. 끝까지 매끄럽게 읽히는가 | 통과 |

**종합**: 통과
```
