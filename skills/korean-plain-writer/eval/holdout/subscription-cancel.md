# 구독 해지 요청 (실용문)

`examples/pairs/`에 없는 새 주제. 실용문(이메일) 장르.

## 원문 (Before)

> 안녕하세요. 다름이 아니라 귀사의 서비스를 이용하던 중 개인적인 사정으로 인하여
> 구독을 해지하고자 하는 바, 관련 절차에 대해 안내해 주실 수 있으실지 문의드립니다.
> 번거로우시겠지만 확인 부탁드립니다.

## 재작성본 (After)

> 안녕하세요. 개인 사정으로 구독을 해지하고 싶습니다. 해지 절차를 안내해
> 주시겠어요?

## 진단 요약

- 번역투: 완곡어법 과다("~하고자 하는 바", "~해 주실 수 있으실지 문의드립니다",
  "번거로우시겠지만")
- 실용문 규칙 적용: 결론(해지 요청)을 먼저, 수식어 최소화

## 의미 보존 체크

| 항목 | 결과 |
|---|---|
| 1. 숫자·날짜·고유명사 | 해당 없음 |
| 2. 인과관계 방향 | 해당 없음 |
| 3. 부정·긍정 | 통과 |
| 4. 직접 인용 | 해당 없음 |
| 5. 핵심 주장·결론 | 통과 (해지 요청 + 절차 안내 요청, 둘 다 유지) |
| 6. 논리 관계 | 통과 |
| 7. 확신의 강도 | 통과 |
| 8. 누락·추가 | 통과 (의례적 완곡 표현만 삭제) |

**종합**: 통과

**참고**: 원문의 "번거로우시겠지만" 같은 순수 인사치레는 실용문 규칙(수식어 최소화)에
따라 뺐습니다. 요청의 실질 내용(해지 사유, 절차 문의)은 그대로 남겼습니다.
