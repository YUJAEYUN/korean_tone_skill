# 퇴사 고민 (에세이)

`examples/pairs/`에 없는 새 주제. 의견/에세이 장르.

## 원문 (Before)

> 최근 퇴사를 고민하고 있는 상황이며, 이는 여러 요인이 복합적으로 작용한 결과라고
> 할 수 있다. 특히 업무에 대한 만족도 저하가 주된 원인으로 작용하였다고 판단되며,
> 이러한 상황이 지속될 경우 정신적 스트레스가 가중될 가능성이 있다고 사료된다.

## 재작성본 (After)

> 요즘 퇴사를 고민한다. 이유는 하나가 아니다. 그중에서도 제일 큰 건 일이 더 이상
> 재미없다는 거다. 이대로 가면 스트레스만 쌓일 것 같다.

## 진단 요약

- 번역투: 완곡·추측 표현 남용("작용하였다고 판단되며", "가중될 가능성이 있다고
  사료된다")
- 어휘: 명사화("작용한 결과라고 할 수 있다")
- 에세이 규칙 적용: 3인칭·보고서체 화법을 1인칭 구어체로, 긴 문장을 짧게 끊어 리듬을
  만듦(문장 길이 편차)

## 의미 보존 체크

| 항목 | 결과 |
|---|---|
| 1. 숫자·날짜·고유명사 | 해당 없음 |
| 2. 인과관계 방향 | 통과 (업무 만족도 저하 → 퇴사 고민, 방향 유지) |
| 3. 부정·긍정 | 통과 |
| 4. 직접 인용 | 해당 없음 |
| 5. 핵심 주장·결론 | 통과 |
| 6. 격식 수준 | 통과 (원문·재작성본 모두 반말체) |

**종합**: 통과
