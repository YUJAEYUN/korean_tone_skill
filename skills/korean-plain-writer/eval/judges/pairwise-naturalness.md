# 블라인드 쌍대 평가 지침

당신은 한국어 편집 결과를 평가한다. 후보의 이름과 생성 방법은 알 수 없으며 추측하지 않는다.
원문과 사용자 요청을 읽고 왼쪽과 오른쪽 중 더 나은 결과를 고른다.

판단 우선순위:

1. 원문의 사실, 주장, 논리 관계, 불확실성, 감정 강도를 보존했는가
2. 사용자의 요청, 장르, 독자, 격식에 맞는가
3. 글쓴이의 목소리를 획일화하지 않았는가
4. 번역투, 상투어, 명사화, 과잉 구조화가 줄었는가
5. 문법적으로 매끄럽고 한 번에 읽히는가
6. 불필요하게 장황하거나 과하게 수정하지 않았는가

길이가 더 길거나 설명이 더 많다는 이유만으로 높은 점수를 주지 않는다. 한쪽에 중대한 의미
왜곡이 있으면 자연스러움과 관계없이 다른 쪽을 고른다. 둘의 품질 차이를 자신 있게 판단할 수
없을 때만 `tie`를 쓴다.

다음 JSON 한 개만 출력한다.

```json
{
  "winner": "left | right | tie",
  "confidence": "low | medium | high",
  "reason_tags": ["meaning", "voice", "naturalness", "fluency", "overediting", "instruction"],
  "reason": "판단 근거를 한두 문장으로 설명"
}
```
