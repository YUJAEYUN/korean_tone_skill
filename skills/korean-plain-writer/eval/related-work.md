# 근거 자료: 평가 방법과 좋은 글쓰기 기준

"이 스킬이 실제로 효과가 있는지 감이 안 온다"는 질문에 답하려고 조사한 자료입니다.
전부 검색으로 실제 존재를 확인한 자료이며, 확인 방식(초록만 봤는지, 원문을 열람했는지)을
항목마다 밝힙니다. 국립국어원 계열 자료는 이 세션 방화벽이 `korean.go.kr`, `data.go.kr`,
`kplain.kr`을 막고 있어 원문 PDF를 직접 열어보지 못했고, 검색 결과 스니펫으로만 확인한
내용입니다. 직접 열람이 필요합니다.

## 1. 텍스트 스타일 전이(Text Style Transfer) 평가: 우리 평가 설계와 거의 일치

NLP 분야에서 "문체만 바꾸고 내용은 유지하는" 과제를 평가할 때 표준적으로 쓰는 3축이
있습니다: **스타일 전이 강도**, **내용 보존**, **유창성(fluency)**. ([A Survey of Text
Style Transfer: Applications and Ethical Implications](https://arxiv.org/pdf/2407.16737),
2024)

우리 설계와 대응시켜 보면:

| TST 3축 | 우리 것 |
|---|---|
| 스타일 전이 강도 | 자연도 등급 (S1/S2/S3 패턴 잔존량. 학습된 분류기 대신 규칙 기반 카탈로그로 대체) |
| 내용 보존 | 의미 보존 6항 체크리스트 (자동 지표 대신 사람이 직접 확인) |
| 유창성 | **없음. 지금 빠져 있는 축** |

**빠진 축(유창성)이 문제인 이유**: 자연도 등급을 올리려고 패턴을 없애다가 문법적으로
어색한 문장을 만들 수 있는데, 지금 체계는 그걸 못 잡습니다. "덜 AI스럽다"와 "문법적으로
매끄럽다"는 별개 축이라는 게 이 분야의 표준적인 구분입니다.

**자동 지표에 대한 경고**: BLEU, 임베딩 코사인 유사도, BERTScore 같은 자동 지표들이
쓰이지만, 최근 연구는 이런 지표들이 신뢰할 만한지에 의문을 제기합니다
([Evaluating Text Style Transfer Evaluation: Are There Any Reliable Metrics?](https://arxiv.org/pdf/2502.04718),
2025). 그래서 우리가 사람 판단(블라인드 A/B)을 자동 지표보다 우선시한 건 이 분야
최신 논의와 방향이 맞습니다.

## 2. 사람 평가 방법론: van der Lee 외, NLG 인간 평가 모범 사례

[van der Lee, Gatt, van Miltenburg, Wubben, Krahmer, "Best practices for the human
evaluation of automatically generated text"](https://aclanthology.org/W19-8643/)
(INLG 2019, 이후 Computer Speech & Language 2021에 확장판)는 NLG 시스템의 사람 평가
방식이 논문마다 제각각이라는 문제를 지적하고 모범 사례를 제시합니다. 주요 지적:
- 검토한 논문 중 33%만 통계 분석을 보고함. "사람이 봤다"는 것만으로는 부족하고,
  평가자 간 일치도(inter-rater agreement) 같은 걸 실제로 계산해서 보고해야 함
- 평가자 수, 과제 설명의 명확성이 결과 신뢰도에 큰 영향을 줌

**우리 것에 적용**: `eval/results.md`는 지금 평가자 1명, 항목 3개입니다. 이 논문 기준으로
보면 "평가자 간 일치도"를 계산할 수 있는 최소 조건(평가자 2명 이상)도 못 채운 상태입니다.
평가자를 늘리는 게 왜 중요한지 근거가 이겁니다.

## 3. LLM을 평가자로 쓰기: 평가자 수 문제의 실용적 해법

[Multidimensional Evaluation for Text Style Transfer Using ChatGPT](https://arxiv.org/pdf/2304.13462)
(2023)은 사람 대신 LLM에게 스타일/내용/유창성을 각각 채점하게 하는 방법을 씁니다.

**우리 것에 적용**: 사람 평가자를 매번 구하기 어려우니, Claude(저) 자신을 "두 번째
채점자"로 써서 더 많은 holdout 항목을 평가하고, 가끔 사람 판단과 얼마나 일치하는지
점검하는 방식을 쓸 수 있습니다. 단, LLM 채점자는 자기 편향(예: 자기가 만든 재작성본을
과대평가하는 경향)이 있을 수 있어서 사람 판단을 완전히 대체하면 안 되고, 사람 판단의
"양"을 보완하는 용도로만 씁니다.

## 4. 국립국어원의 쉬운 한국어 쓰기 지침 (검증 필요, 아직 직접 확인 못 함)

국립국어원이 실제로 이런 지침을 공식 발간했다는 것까지는 검색으로 확인했습니다.

- [쉬운 공문서 쓰기 길잡이](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=&etc_seq=700) (2022): 쉬운 글쓰기, 국민 눈높이에서 표현하기, 정확하게 쓰기, 문서
  작성/구성/사후 검토, 유형별 실무 문서 쓰기(공고문·민원 회신문·보고서·SNS 홍보문) 순서로
  구성된다고 함. **유형별로 다르게 쓴다는 접근은 우리 `genre-rules.md`와 방향이 같습니다.**
- [한눈에 알아보는 공공언어 바로 쓰기(개정판)](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=&etc_seq=699) (2024)

**한계**: 방화벽 때문에 실제 예시 목록(구체적으로 어떤 한자어를 뭐라고 바꾸라고 하는지)을
못 봤습니다. `plain-vocabulary-map.md`가 지금은 제가 직접 만든 55개짜리 목록인데, 이
자료를 실제로 열람해서 정부가 공인한 대체어 목록과 대조하면 훨씬 근거가 탄탄해집니다.
**직접 접근 가능한 환경에서 이 문서를 한 번 확인해 보시는 걸 권합니다.**

## 5. 한국어 가독성 지수 연구 (자동 측정 지표 후보, 아직 미구현)

한국어 읽기 텍스트의 난이도를 어휘 난이도·문법 난이도·문장 길이를 다중회귀분석으로
결합해 하나의 공식으로 만든 연구가 있습니다 ([한국어 읽기 텍스트의 난이도 측정 공식
개발에 관한 연구](https://dspace.kci.go.kr/handle/kci/666689), 160개 텍스트 샘플, 전문가
평정과 비교 검증). 원문이 KCI 학술 데이터베이스 안에 있어 이번에 실제 공식(회귀계수)까지는
확인하지 못했습니다.

**우리 것에 적용(미구현)**: 지금 `change_rate_check.py`는 "원문과 얼마나 다른가"만 잽니다.
"재작성본이 객관적으로 더 쉬워졌는가"를 재는 지표가 따로 없습니다. 이 공식을 그대로
가져다 쓸 수는 없어도(원문 미확인), 평균 문장 길이·`plain-vocabulary-map.md`에 등재된
어려운 표현의 잔존 개수 같은 간단한 자체 지표는 지금도 만들 수 있습니다.

## 6. 쉬운 말 쓰기가 실제로 이해도를 높이는가 (효과는 있지만 "규칙만 지켰다고 성공은 아님")

의학 논문 초록을 일반인용 쉬운 요약(Plain Language Summary)으로 바꾸는 연구들에서:
- 일반인은 쉬운 요약을 과학 초록보다 선호했고 실제로 지식 습득에도 더 도움이 됨
  ([Zeitschrift für Psychologie, 2022](https://econtent.hogrefe.com/doi/10.1027/2151-2604/a000570))
- 그런데 실제로 만들어진 "쉬운 요약"들을 가독성 지수로 측정해보니, 큰 표본에서 겨우
  2.8%만 "쉬운 영어" 기준을 통과함. 쉽게 쓰려는 의도와 실제로 쉬워졌는지는 별개
  ([JMIR, 2025](https://www.jmir.org/2025/1/e50862))

**우리 것에 적용**: 이게 이번 조사에서 가장 뼈아픈 발견입니다. "규칙(어휘 매핑표, 구조
템플릿, 장르 규칙)을 적용했다"는 게 "실제로 쉬워졌다"를 보장하지 않습니다. 지난번
변경률 가드처럼, 규칙을 그대로 믿지 말고 결과물을 직접 측정해야 한다는 이번 세션의
교훈과 정확히 같은 이야기입니다.

## 정리: 지금 당장 반영할 수 있는 것과 못 하는 것

| 할 일 | 상태 |
|---|---|
| 평가에 "유창성" 축 추가 (자연스러움과 별개로) | 이번에 반영 |
| 평가자 부족 문제를 LLM 채점자로 보완 (사람 대체는 아님) | 이번에 방향만 기록, 실행은 다음 |
| 국립국어원 공식 지침 대조 | 방화벽 때문에 이번엔 못 함, 직접 접근 가능한 환경에서 확인 필요 |
| 한국어 가독성 공식 도입 | 원문 미확인, 간단한 자체 지표(평균 문장 길이 등)로 대체 가능 |
| "규칙 적용 = 실제 효과"라고 가정하지 않기 | 원칙으로 기록, `eval/`에서 결과물을 직접 재는 습관 유지 |
