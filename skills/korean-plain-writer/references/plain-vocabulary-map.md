# 어휘 순화 매핑표

DaleSeo/humanizer의 "어휘" 카테고리는 "이 단어는 AI스럽다"까지만 판정합니다. 그다음
질문, **"그럼 뭐라고 쓸까"**를 이 표가 답합니다.

## 운영 방식

- 완벽한 표로 시작할 필요는 없습니다. 아래 시드(약 55개)로 출발해서, 실제 윤문 작업 중
  자주 나오는 단어를 계속 채워 넣으세요.
- SKILL.md 3단계에서 이 표에 없는 단어를 새로 바꿨다면 표에 추가하세요. 애매하면
  사용자에게 "이번에 새로 다듬은 표현, 표에 추가할까요?"라고 물어도 됩니다.
- "비고"에 "문맥 따라"라고 적힌 항목은 기계적으로 바꾸지 말고 문맥을 보고 판단하세요.
