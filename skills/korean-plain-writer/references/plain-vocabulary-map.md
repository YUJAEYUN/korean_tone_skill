# 어휘 순화 매핑표

DaleSeo/humanizer의 "어휘" 카테고리는 "이 단어는 AI스럽다"까지만 판정합니다. 그다음
질문, **"그럼 뭐라고 쓸까"**를 이 표가 답합니다.

## 운영 방식

- 완벽한 표로 시작할 필요는 없습니다. 아래 시드(약 55개)로 출발해서, 실제 윤문 작업 중
  자주 나오는 단어를 계속 채워 넣으세요.
- SKILL.md 3단계에서 이 표에 없는 단어를 새로 바꿨다면 표에 추가하세요. 애매하면
  사용자에게 "이번에 새로 다듬은 표현, 표에 추가할까요?"라고 물어도 됩니다.
- "비고"에 "문맥 따라"라고 적힌 항목은 기계적으로 바꾸지 말고 문맥을 보고 판단하세요.
- **이 표보다 훨씬 큰 자료가 이미 있습니다.** 국립국어원이 1976년부터 지금까지
  다듬어 온 순화어 데이터베이스가 누리집에 공개돼 있고(2026년 기준 18,000건 이상),
  국민 신청을 받아 계속 갱신됩니다. 찾아 들어가기: 국립국어원 누리집 → 개선 →
  다듬은 말. 이 표에 없는 단어는 먼저 여기서 검색해 보는 게 직접 만드는 것보다
  낫습니다. (이 세션은 `korean.go.kr` 접근이 막혀 있어 직접 검색은 못 했습니다.)

## 국립국어원 기준 확장

아래는 국립국어원 『쉬운 공문서 쓰기 길잡이』(2022, 8~20쪽 "제1장 쉽게 쓰기")에 실린
실제 보기·권장 표현을 정리한 것입니다. 위 시드 표와 달리 제가 만든 게 아니라 정부
공인 자료 기준입니다. 원문은 국립국어원이 발간하는 자료라 공익 목적 재사용을
전제로 합니다(비상업적 이용, 출처 표시). 사용자가 실제 자료를 캡처해서 확인해
주었습니다.
