# 한국어 글쓰기 상황 분석

장르명 하나로 글쓰기 방식을 결정하지 말고 아래 순서로 분석한다.

1. **목적**: 이해, 안내, 행동 유도, 설득, 판단 지원, 기록, 관계 유지, 표현 중 주목적 하나를 고른다. 필요한 경우 부목적을 따로 적되 주목적과 섞지 않는다.
2. **독자**: 전문성, 배경지식, 연령·언어 접근성, 작성자와의 관계를 파악한다.
3. **다음 행동**: 읽은 뒤 독자가 알아야 하거나 해야 할 일을 한 문장으로 쓴다.
4. **매체**: 이메일, 공지, 보고서, 웹, 모바일, 발표, 논문 등 읽기 환경을 적는다.
5. **격식**: 친근함, 일반 존댓말, 공식 격식 중 하나를 기본값으로 정한다.
6. **위험도**: 잘못 이해했을 때의 피해를 낮음·중간·높음으로 판정한다.
7. **장르**: 마지막에 보조 정보로 판별한다.

세부 기준과 반환 형식은 `references/context-profile.md`를 따른다.

정보가 부족해도 합리적으로 추론한다. 결과를 크게 바꾸는 불확실성만 질문하고, 나머지는 가정으로 표시한다. 사용자에게 물을 수 없거나 사용자가 빠른 결과를 원하면 가장 안전한 가정을 택한다. 사용자가 원하지 않으면 분석 전문을 출력하지 말고 다음 스킬에 전달한다.
