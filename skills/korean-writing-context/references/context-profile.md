# 상황 프로필

다음 형식을 내부 작업 상태로 사용한다.

```yaml
task: 새 글 작성 | 부분 수정 | 전체 재작성 | 진단
purpose: 안내
audience: 일반 고객
reader_action: 중단 일시를 확인하고 필요한 작업을 미리 저장한다
medium: 이메일
relationship: 기업에서 고객에게
formality: 일반 존댓말
risk: 중간
genre: 서비스 공지
priorities:
  - 정확성
  - 행동 가능성
  - 명료성
preserve:
  - 날짜와 시간
  - 서비스명
  - 보상 조건
assumptions: []
```

## 위험도

- **높음**: 잘못 이해하면 안전, 건강, 법적 권리, 재산에 피해가 생길 수 있음
- **중간**: 업무 실패, 비용, 일정 차질 또는 고객 불만이 생길 수 있음
- **낮음**: 피해가 작고 쉽게 되돌릴 수 있음

위험도가 높으면 표현을 매끄럽게 만드는 것보다 전문용어, 조건, 예외, 수치와 불확실성을 먼저 보존한다.
