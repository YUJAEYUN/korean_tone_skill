# 1부 제2장 국민의 처지에서 표현하기 (21~27쪽)

## 핵심 원칙

- 공공언어에서는 명령적·권위적으로 느껴지는 표현을 피한다. (21쪽)
- 성별, 지역, 연령, 인종, 국가, 장애 등에 관한 차별적 표현을 피한다. (24쪽)
- 국민이 불편함이나 거부감을 느끼지 않도록 수신자의 처지에서 표현을 고른다. (21쪽)
- 특정 집단에 대한 고정관념을 강화할 수 있는 정보, 문맥상 불필요한 인적 정보, 일부 사람만 이해할 수 있는 정책 별칭도 점검한다. (24~26쪽)

## 1. 고압적 표현 삼가기 (21~23쪽)

| 쪽 | 원문의 문제 유형 | 예시의 수정 방향 |
| --- | --- | --- |
| 21 | 복약 지시를 명령형 종결 형식으로 제시 | 독자에게 직접 말하는 공손한 권유형으로 바꿈 |
| 22 | 창고 요건을 명령형으로 규정 | 갖추어야 할 요건임을 설명하는 형식으로 바꿈 |
| 22 | 전화 문의를 간략한 명령형 명사구로 제시 | 문의하기를 바란다는 완곡한 문장으로 바꿈 |
| 22 | 지원서의 전문 분야 표시를 명령형으로 지시 | 표시해 달라는 공손한 요청으로 바꿈 |
| 22 | 철도 시설물 촬영 수칙을 명령형으로 지시 | 안전하게 촬영하기를 바란다는 형식으로 바꿈 |

| 23 | 처분의 적법성 판단을 권위적인 단정 표현으로 끝냄 | 불필요한 권위적 종결 표현을 덜어 내고 평서형으로 끝냄 |
| 23 | 손실과 처분의 과중함을 권위적인 단정 표현으로 반복 | 이유 관계를 간결하게 연결하고 평서형으로 바꿈 |

### 세부 원칙

- ‘~을 것’처럼 직접 명령하는 형식보다 대상과 문맥에 맞는 공손한 요청·권유·의무 표현을 쓴다. (21~22쪽)
- ‘~ 바람’처럼 일방적으로 느껴질 수 있는 표현은 완결된 공손한 문장으로 바꾼다. (22쪽)
- 판정이나 명령이 필요한 문서에서도 필요 이상으로 위압적인 종결 표현을 쓰지 않는다. (23쪽)
- 권위적인 문체를 만드는 군더더기 표현은 뜻을 손상하지 않는 범위에서 덜어 낸다. (23쪽)

## 2. 차별적 표현 삼가기 (24~26쪽)

| 쪽 | 원문의 문제 유형 | 예시의 수정 방향 |
| --- | --- | --- |
| 24 | 장애 학생을 특별한 관심과 배려의 대상으로만 제시 | 장애를 시혜의 대상으로 보는 인상을 줄이고 차이에 공감하도록 가정교육을 요청하는 내용으로 바꿈 |
| 25 | 여행 지원 대상인 고령층을 소외된 집단으로 규정 | 소외 여부를 단정하지 않고 지원 대상을 중립적·존중적인 호칭으로 제시 |

### 용어 설명 상자

- 24쪽은 장애인을 가리키는 여러 호칭이 왜 서로 다르게 받아들여지는지를 설명하고, 법적·가치중립적인 용어를 사용하는 방향을 제시한다.
- 25쪽은 고령층을 가리키는 법적 용어, 존칭, 외래어, 중립적 연령 표현이 상황에 따라 쓰임이 다르므로 문맥에 맞추어 선택해야 한다고 설명한다.

# 1부 제3장 정확하게 쓰기 (28~35쪽)

## 핵심 원칙

- 행정 문서는 맞춤법·띄어쓰기·외래어 표기 등 어문 규범에 맞게 작성한다. (28~29쪽)
- 오자와 탈자는 내용의 신뢰성과 이해 가능성을 해치므로 반드시 검토한다. (29쪽)
- 단어는 문맥에 맞는 의미로 사용한다. (29~30쪽)
- 주어·목적어·수식어와 서술어의 호응, 조사와 어미, 문장 성분의 생략 여부를 점검한다. (30~33쪽)

## 1. 표기의 정확성 (28~29쪽)

### 맞춤법 예시 (28쪽)

| 문제 표현의 핵심 | 권장되는 수정 |
| --- | --- |
| 연도를 뜻하는 말에 두음법칙을 적용하지 않음 | 연도를 뜻하는 표준 표기로 수정 |
| 서식의 빈칸을 뜻하는 말의 첫소리를 잘못 적음 | ‘난’에 해당하는 표준 표기로 수정 |
| 비율을 뜻하는 접미 요소의 첫소리를 잘못 적음 | 받침 뒤에 오는 표준 표기로 수정 |
| 긍정·부정 답변의 ‘아니요’를 서술어 기본형처럼 적음 | 응답 표현에 맞는 종결형으로 수정 |
| 받침 없는 명사 뒤의 ‘이에요’ 준말을 잘못 표기 | ‘예요’ 형식으로 수정 |
| 수단을 나타내야 하는 문장에서 원인을 나타내는 연결 표현 사용 | 수단·방법을 나타내는 형식으로 수정 |

### 띄어쓰기 예시 (28~29쪽)

| 문제 표현의 핵심 | 권장되는 수정 |
| --- | --- |
| 여부, 사진 위, 날인 여부를 모두 붙여 씀 | 명사 단위에 따라 띄어 씀 |
| 금액의 단위를 숫자에 붙여 씀 | 숫자와 단위를 띄어 씀 |
| 질문형 어미를 앞말과 띄어 씀 | 어미를 앞말에 붙여 씀 |
| 연결 어미가 결합한 말을 띄어 씀 | 어미를 앞말에 붙여 씀 |
| 어떤 일을 하는 데 걸리는 시간을 나타내는 의존 명사를 붙여 씀 | 의존 명사를 띄어 씀 |
| 때를 나타내는 의존 명사를 붙여 씀 | 의존 명사를 띄어 씀 |

### 외래어 표기 예시 (29쪽)

- 마케팅을 잘못 적은 표기를 바로잡는다.
- 불이익이나 벌점을 뜻하는 외래어의 모음을 표준 표기에 맞게 고친다.
- 포털사이트에서 ‘사이트’의 된소리를 표준 표기로 고친다.
- 서명용 펜을 가리키는 외래어를 표준 표기로 고친다.

### 오탈자 예시 (29쪽)

- 화물이 어떤 지역을 거쳐 간다는 동사를, 다른 뜻의 동사로 잘못 적은 글자를 바로잡는다.
- 신청 조건에 맞는다는 뜻의 서술어에서 빠진 글자를 보충한다.

## 2. 표현의 정확성 (29~33쪽)

### 의미에 맞는 단어 사용 (29~30쪽)

| 쪽 | 문제 | 수정 방향 |
| --- | --- | --- |
| 29 | 반환하지 않는다는 문장에서 ‘모두’를 뜻하는 말을 사용 | 부정문과 어울려 ‘전혀’의 뜻을 나타내는 말로 변경 |
| 29 | 재산 소유의 유무를 확인한다고 표현 | 소유 여부를 확인한다는 자연스러운 표현으로 변경 |
| 30 | 예매 대상 설명에서 사람을 뜻하는 말과 우대 대상의 의미가 뒤섞임 | 연령 조건과 기기 사용의 어려움을 각각 명확히 서술 |
| 30 | 공식 이름을 의미하면서 ‘순수한 이름’이라고 표현 | 본명을 뜻하는 정확한 단어로 변경 |
| 30 | 조사 결과 문제점이 자연스럽게 발견된 상황에 ‘도출’을 사용 | 발견의 의미를 가진 서술어로 변경 |
| 30 | 안전을 위반한다는 식으로 목적어와 서술어가 어울리지 않음 | 안전을 고려하지 않았다는 뜻으로 변경 |

### 문장 성분의 호응 (30~31쪽)

- 원인이 된 사실, 재산 소유 여부, 활동한 경험처럼 관형절과 명사를 자연스럽게 연결한다.
- 전환하려는 창업자와 전환을 희망하는 창업자를 구별해 병렬 구조를 맞춘다.
- 제재를 ‘조치한다’고 하지 않고 제재 조치를 한다는 구조로 고친다.
- 어떤 칸에 내용을 적는지 조사를 분명하게 표시한다.
- 서면 평가로 바뀔 수 있다는 정보와 평가 결과 통보 정보를 서로 다른 술어에 연결한다.
- 자외선 차단제처럼 문맥상 빠진 목적어를 보충한다.
- 세금 신고를 ‘위해서는’이라고 연결하기보다 신고하려면 사업자등록이 필요하다는 조건 관계로 정리한다.
- 고용주·사업주와 소재 지역의 수식 관계가 뒤섞이지 않도록 어순을 조정한다.
- 열차가 서행하는 이유, 적용 구간, 승객에게 요청하는 내용을 자연스러운 순서로 배열한다.
- 지원 대상 선정 방법을 설명하는 문장은 사업의 주체 또는 ‘선정 방법’이라는 주어에 맞추어 끝까지 호응시킨다.

### 적절한 문법 요소 사용 (32쪽)

| 문제 유형 | 수정 방향 |
| --- | --- |
| 높임 표현의 중복 | 이미 높임이 포함된 호칭에 불필요한 복수·존칭 요소를 덧붙이지 않음 |
| 공직자 직함에 사적 높임 사용 | 기관 문서에 맞는 객관적 직함으로 표시 |
| 이유를 나타내는 구성의 중복 | 명사형 구성과 서술어를 간결하게 연결 |
| 현재 상태를 과거 관형형으로 잘못 수식 | 의미에 맞는 관형형으로 수정 |
| 기준 시점을 뜻하는 문맥에 조건 표현 사용 | 시점을 뜻하는 연결 표현으로 수정 |
| 사동 표현의 불필요한 사용 | 주체가 직접 하는 행위로 표현 |
| ‘용이하다’의 품사와 문장 구조 불일치 | 부사형을 갖춘 문장으로 수정 |

### 생략된 내용 보충 (33쪽)

- 사업장이 여러 개인 사람과 사업을 하지 않는 사람에게 각각 무엇을 적거나 비워 두어야 하는지 서술어를 모두 갖춘다.
- 전화번호의 지역 번호·국 번호·개별 번호가 어떤 순서로 수록되는지 빠진 정보를 보충한다.

## 3. 점검표 (33쪽)

| 영역 | 확인할 내용 |
| --- | --- |
| 표기 | 오자·탈자 여부, 어문 규범에 어긋나는 표기 여부 |
| 표현 | 문맥에 맞는 단어인지, 문장이 어법에 맞는지 |

34쪽은 빈 쪽이고, 35쪽에는 2부의 표제만 제시된다.

# 3부 제1장 공고문 쓰기 (60~68쪽)

## 핵심 원칙

- 공고문은 일반 대중에게 일정한 사실을 널리 알리는 문서이므로 복잡한 정보를 쉽게 전달해야 한다. (60쪽)
- 권위적이고 단정적인 표현을 주의한다. (60쪽)
- 공고 제목에 공고 대상을 드러내고, 많은 정보는 항목으로 나누며, 지원 절차에 따른 순서로 배열한다. 추가 문의를 위한 담당자 연락처도 제시한다. (61쪽)

## 형식 보기 (61쪽)

고객 평가단 모집 사례를 이용해 다음 정보를 순서대로 보여 준다.

1. 모집 대상과 세부 자격
2. 활동 내용과 활동 지역 선택
3. 활동 기간
4. 활동 혜택
5. 모집 기간
6. 지원서 제출 방법과 전자우편 주소
7. 결과 발표일과 발표 매체
8. 문의 전화번호

# 3부 제2장 민원 문서용 서식 만들기 (69~78쪽)

## 실습: 개선이 필요한 민원 서식 (77~78쪽)

교정부호로 표시된 주요 수정 사항은 다음과 같다.

- 신청 내용, 공개 신청 여부, 신청 대상자 등 복합 명사의 띄어쓰기 정리
- 주민등록번호를 공개할 경우 어느 부분을 공개하는지 명시

- 신청인과 위임인의 항목 표시를 일정하게 정리
- 신청인 자격을 신청 대상자와의 관계라는 뜻이 분명한 명칭으로 변경
- 휴대전화 번호의 띄어쓰기 수정
- ‘기재하여야’ 같은 딱딱한 표현을 간결하게 수정
- 여러 사람을 뜻하는 어려운 한자 표현을 일상적인 말로 변경
- 신청서와 별지 사이에 간인·서명해야 한다는 절차를 풀어서 설명
- 친권과 후견의 병렬 관계를 분명히 표시
- 아포스티유가 무엇인지 각주로 설명
- 출생 연월일 표기를 바로잡음
- 형벌 규정을 국민이 이해하기 쉬운 능동적 문장으로 변경
- 앞사람과 같은 처벌을 받는다는 뜻을 직접 서술

78쪽은 완성된 새 서식을 조판한 것이 아니라 교정부호를 적용한 보기이므로, 글자 단위 대조가 필요할 때에는 원본 확대 화면을 확인해야 한다.

# 3부 제4장 누리소통망서비스 홍보 글 쓰기 (96~103쪽)

## 1. 누리소통망서비스 홍보 글의 성격 (96쪽)

- 온라인 관계망 서비스를 이용해 정보를 전달하고 정책을 홍보하는 글이다.
- 공공기관과 국민이 신속하게 정보를 주고받고, 이용자가 댓글이나 재전파로 참여할 수 있는 쌍방향 매체라는 특징이 있다.
- 기관은 페이스북·트위터·인스타그램·블로그·카카오스토리·유튜브 등 각 채널의 이용자 특성을 고려해 글·사진·영상·카드뉴스 등을 게시한다.
- 국민의 접근성이 높으므로 쉽고 자연스러운 문장으로 작성한다.
- 핵심이 빠르게 보이도록 간결하고 명확하게 구성한다.

## 2. 일반적인 구성 방식 (97쪽)

- 보도 자료가 문자 중심이라면 누리소통망서비스 글은 사진·그림·영상 같은 시각 자료의 비중이 크다.
- 핵심 내용은 한두 문장의 짧은 글로 제시한다.
- 상세 내용을 확인할 수 있는 연결 문서의 웹 주소를 덧붙인다.
- 핵심어 표시, 핵심 내용, 구체적인 정보, 연결 문서가 시각적으로 구분되어야 한다.

### 97쪽 그림이 보여 주는 정보 구조

코로나19로 소득이 줄어든 가구를 대상으로 한 한시적 생계 지원 사례를 통해 다음 요소를 보여 준다.

1. 첫 문장에서 대상과 행동을 제시
2. 핵심어에 해시태그를 사용
3. 신청 사이트 연결
4. 시각 자료 안에서 소득 기준, 지원 금액, 지역별 재산 기준을 구분
5. 지원 재원이 세금이라는 홍보 메시지를 함께 표시

## 3. 작성 과정에서 주의할 점 (98~102쪽)

| 의심 증상, 의료기관 방문, 검사 권고, 보건소 검사의 관계가 불분명 | 증상이 있어 의료기관을 방문했고 검사를 권고받은 사람이라는 조건을 순서대로 서술 |

### 라. 어법에 맞는 문장을 썼는가? (100~101쪽)

- 조건을 나타내는 말이 중복된 문장은 하나의 조건 표현으로 간결하게 고친다.
- 조사나 목적어를 지나치게 생략해 문장 성분이 호응하지 않는지 확인한다.

### 마. 자연스럽게 읽을 수 있도록 작성했는가? (100~101쪽)

| 문제 유형 | 수정 방향 |
| --- | --- |
| 영어와 한글을 섞은 유행식 표기 | 한글 표기로 정리 |
| 불필요한 사동 표현 | 상태가 변한다는 자연스러운 서술로 변경 |
| 추상적 사실에 ‘존재하다’를 사용 | 일상적인 ‘있다’로 변경 |
| 종교 활동의 방식과 장소를 같은 층위로 잘못 연결 | 비대면으로 하는 방식과 실외에서 하는 장소를 각각 맞는 조사·서술어로 연결 |

### 바. 적절한 분량의 정보를 제시했는가? (101쪽)

예방 접종 뒤의 이상 반응 조사 사례에서는 기간, 조사 대상, 분석 행위, 분석 결과를 한 문장에 모두 넣지 않고 두 문장으로 나눈다. 또한 증상을 병렬로 연결할 때 문맥에 맞는 접속 표현을 사용한다.

### 사. 논리적으로 연결되도록 제시했는가? (102쪽)

지원 안내문 사례에서는 안내문을 받는 대상과 실제 지급 대상이 같다고 오해하지 않도록 다음 관계를 명확하게 한다.

1. 안내문은 지급 대상 모두에게 보내는 문서가 아니다.
2. 지급 가능성이 큰 가구에 우선 발송한다.
3. 안내문 수령 자체가 지급 확정을 뜻하지 않는다.
